1

Apify API 設定

還沒有帳號？到 console.apify.com 免費註冊

取得方式：登入 → 頭像 → Settings → Integrations → Personal API tokens → 建立一組 token

Token 只存在你這台瀏覽器的 localStorage，不會送到別的地方（除了 Apify 本身）。

4

抓取設定

50
10 200
建議 50 筆：多數 hashtag 一天產出數則到十幾則，50 筆通常涵蓋 1～3 個月。冷門 hashtag 或想拉到一年可調至 100～150。這是「跟 Apify 要多少筆原始資料」，不是最後看到的筆數（之後還會依日期篩選），數字越大耗費額度越多、抓取也越久。

預設抓取最近一年，可自行調整或清空。日期篩選是抓回來後在網頁端依貼文時間過濾（Apify 沒有原生日期參數），若結果太少代表該期間本來就沒多少貼文，試著調高上面的抓取筆數。
