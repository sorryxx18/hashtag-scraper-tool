🏷️ Hashtag 資料抓取工具

自己填 Apify Token，選平台、Hashtag、日期區間，一鍵抓取並匯出 CSV。設定只留在你自己的瀏覽器裡。

1Apify 設定

還沒有 Apify 帳號？免費註冊 →
申請方式：先到 console.apify.com 免費註冊（有免費額度）→ 登入後點右上角頭像「Settings」→ 左側「Integrations」→「Personal API tokens」→ 建立一組 token（格式 apify_api_開頭），複製貼到上面欄位。
這個數字代表「跟 Apify 要多少筆原始資料」，不是最後看到的筆數（之後還會依日期區間過濾）。建議 50：多數 hashtag 一天大約產出數則到十幾則貼文，50 筆通常能涵蓋最近 1～3 個月；如果 hashtag 冷門或想拉長到一年，可以調到 100～150。數字越大，Apify 額度花費越多，抓取時間也越久，建議先用預設值試抓一次，篩選後筆數太少再往上調。

2平台

目前只支援這兩個平台（都能匿名抓公開 hashtag 頁面）。TikTok / Twitter(X) 之後如果確認有穩定的抓取方式會再加；Facebook / Dcard 因為服務條款明文禁止自動化蒐集且有反爬機制，不考慮加入。

3Hashtag（最多 5 個，不用打 # 符號）

只填想抓的欄位即可，其餘留空不影響。

4日期區間

預設抓最近一年（可自行調整或清空）。篩選是抓回來後在網頁端依貼文時間過濾，不是 Apify 原生支援——如果篩完筆數很少，代表這個 hashtag 在這段期間貼文本來就不多，可以調高上方「每個 Hashtag 抓幾筆」。
